Defect Tracking

Interactive Bug Report Showcase

Click on each defect ticket below to view the actual reproduction steps, actual vs. expected results, and QA root-cause analysis.

Actual Defect

When splitting payment 50/50 between Cash and Card while offline, the sync queue failed to reconcile total amount on reconnect, leading to a balance mismatch in the EOD register.

Expected Behavior

Split payment transactions created offline must accurately store both split segments and reconcile correctly upon internet reconnection.

Reproduction Steps
1. Launch POS in Offline Mode.
2. Create an order with 3 items totaling $100.
3. Select Split Payment: $50 Cash, $50 Card.
4. Complete order and re-enable network connection.
5. Check EOD shift summary report.
QA Root-Cause Note: JSON transaction payload was overwriting split payment sub-objects when queuing offline storage in IndexedDB.
Actual Defect

Receipt printing hung indefinitely when customer names contained non-ASCII characters or emojis, locking subsequent print jobs.

Expected Behavior

Printer driver module should sanitize or correctly encode UTF-8 bytes to ESC/POS format without freezing the queue.

Reproduction Steps
1. Place order with special character notes: "Table 5 — Spécial".
2. Trigger Print Receipt command.
3. Observe printer status in task manager.
QA Root-Cause Note: Raw socket byte stream was not handling multi-byte UTF-8 string encoding offsets properly.
Actual Defect

When JWT access token expired during checkout form completion, submitting the form redirected to login and wiped user form state without warning.

Expected Behavior

Silent refresh token should seamlessly renew session in background or preserve user draft cart state upon re-login.

Reproduction Steps
1. Add items to cart and wait 15 minutes for token expiry.
2. Click "Proceed to Checkout".
3. Observe auth interceptor behavior.
QA Root-Cause Note: Axios response interceptor lacked automatic 401 refresh token retry logic.
